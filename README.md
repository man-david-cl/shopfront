# Nova/Shop

Production-quality Next.js + TypeScript + Tailwind e-commerce frontend starter.

## Run
npm install
npm run dev

## Included
- Responsive storefront homepage
- Product catalog with search/category filtering
- Product detail pages
- Cart and checkout UX
- Account and orders placeholders
- Reusable header, footer and product cards
- Mock product data and `/api/products` route
- Clean Tailwind 4 styling

## Backend phase
Replace `src/lib/data.ts` with your API/DB repository and connect auth, carts, inventory, orders, and payment webhooks. For Nigeria, Paystack is a natural payment integration; Stripe is another option where applicable.
